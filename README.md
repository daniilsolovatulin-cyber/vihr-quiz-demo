# Вихрь — демо

Интерфейс викторины с одиночной игрой и комнатами. Фоновые изображения и конфетти перенесены из предоставленного QuizMe HTML.

## Изменения
- Убрана системная синяя подсветка при касании. Фокус с клавиатуры сохранён.
- button.wav — нажатия, bass.wav — неверные ответы и ошибки, victory.wav — победа.
- Настройки доступны гостям: общий звук, отдельное отключение эффектов и громкость музыки/эффектов. Выбор сохраняется в браузере.
- Конфетти QuizMe на успешном одиночном результате (90%+) и финальном табло комнаты; автоматическая очистка и reduced-motion.
- Все существующие лоадеры и процентные индикаторы сохранены. Добавлены лоадеры восстановления сессии и статистики игрока.
- Удалены неиспользуемая клиентская генерация Groq и пустые обработчики.

## Публикация
render.yaml создаёт бесплатный Static Site из public и включает автодеплой новых коммитов.
Демо использует существующий API https://virh-backend-4.onrender.com (public/config.js).
Backend, ключи генератора и сохранение данных остаются на существующем сервисе. Его первый ответ после простоя может задерживаться.

## Локальный запуск
Статику public можно раздать любым HTTP-сервером. Для отдельного backend см. server/README.md; нужны JWT_SECRET и GROQ_API_KEYS. Не публикуйте .env и SQLite-базу.

## Проверка
Проверены синтаксис всех frontend-скриптов, маршрутизация WAV, отключение и сохранение звуков, подавление двойных кликов и повторных ошибок. Лоадеры исходного архива сохранены.
